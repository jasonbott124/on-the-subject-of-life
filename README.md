# On the Subject of Life*

Website for Jason Bott's long-form podcast (formerly *Heights of Humanity*), hosted free on GitHub Pages. Replaces the Squarespace site at heightsofhumanitypodcast.com.

- `index.html` — the whole site. **To add an episode**, add an entry at the top of the `EPISODES` list near the bottom of the file.
- `assets/style.css` — styles (forest green from the original site, leaf-shaped buttons).
- `assets/img/` — recording photos.
